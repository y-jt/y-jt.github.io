create_pdf

发表于 2024-10-16 更新于 2024-11-19

C++生成pdf，包括文字图像等，不能编辑已有pdf。

libharu官网：http://libharu.org/

github,Wiki查看使用说明

解压后，使用cmd，cmake编译,build和库目录同级

mkdir build

cmake ../libharu-RELEASE_2_3_0

vs打开sln，生成lib和dll，cmake设置的vs

把库头文件和build/include/hpdf_config.h放一起
